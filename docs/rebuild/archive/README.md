# Rebuild archive

Point-in-time documents from the 2.x rebuild, kept for history.

**Nothing in this folder is current.** Each file was an audit or a work list
written on the date in its name, and each describes the state of the branch on
that day in the present tense. The rebuild finished: 2.0.0 "Rose" shipped to
production on 2026-09-20.

If you need to know what is true now, read the code, then `CLAUDE.md`, then
`docs/rebuild/decisions.md` — in that order.
